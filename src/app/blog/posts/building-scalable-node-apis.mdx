- **Rate limiting** with Redis
- **Queue-based processing** with Bull

### Data Validation and Security

Security cannot be an afterthought. Every API endpoint needs:

```javascript
const rateLimit = require('express-rate-limit');
const helmet = require('helmet');

// Rate limiting
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes
  max: 100 // limit each IP to 100 requests per windowMs
});

app.use(limiter);
app.use(helmet());
```

## Performance Optimization Strategies

### 1. Caching Layer

Implementing Redis caching reduced database queries by 70%:

```javascript
const redis = require('redis');
const client = redis.createClient();

const cacheMiddleware = (duration) => {
  return async (req, res, next) => {
    const key = `cache:${req.originalUrl}`;
    const cached = await client.get(key);
    
    if (cached) {
      return res.json(JSON.parse(cached));
    }
    
    res.sendResponse = res.json;
    res.json = (body) => {
      client.setex(key, duration, JSON.stringify(body));
      res.sendResponse(body);
    };
    
    next();
  };
};
```

## Monitoring and Observability

You can't optimize what you can't measure. Essential metrics to track:

- Response time percentiles
- Error rates by endpoint
- Database connection pool usage
- Memory and CPU utilization

## Deployment and DevOps

### Environment Configuration

Using environment-specific configurations prevented many production issues:

```javascript
const config = {
  development: {
    database: {
      host: 'localhost',
      // dev settings
    }
  },
  production: {
    database: {
      host: process.env.DB_HOST,
      // production settings
    }
  }
};
```

## Key Takeaways

1. **Design for failure**: Assume external services will fail
2. **Monitor everything**: Logging and metrics are not optional
3. **Test under load**: Performance testing should be part of your workflow
4. **Security first**: Validate inputs, sanitize outputs, authenticate everything

Building scalable APIs is an iterative process. Start with good foundations, measure continuously, and optimize based on real data, not assumptions.
